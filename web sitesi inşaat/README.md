# Kılıçaslan İnşaat web sitesi

Statik HTML, CSS ve JavaScript ile hazırlanmıştır. Derleme veya sunucu tarafı kod gerektirmez.

## GitHub Pages yayını

1. `index.html`, `styles.css` ve `script.js` dosyalarını GitHub deposunun kök dizinine yükleyin.
2. Depoda **Settings → Pages** bölümünü açın.
3. Yayın kaynağı olarak `Deploy from a branch`, `main` ve `/(root)` seçin.
4. Kaydedilen Pages adresinden siteyi açın.

## İçerik ve fotoğraflar

- Proje galerisi ve görsel alanları fotoğrafları Unsplash CDN’den yükler. İlk yayın öncesi bağlantıları ve marka kullanımına uygun görsel seçimlerini gözden geçirin.
- Galerideki fotoğraflar gerçek mimari/inşaat fotoğraflarıdır; Kılıçaslan İnşaat’ın doğrulanmış proje portföyü olarak sunulmamaktadır.
- Harici fotoğraf ve Google Fonts bağlantıları için internet bağlantısı gerekir. Fotoğraflar yüklenemezse yer tutucu yüzeyler görünür kalır.
- Teklif formu, kullanıcının gönderdiği alanlarla WhatsApp’ta önceden doldurulmuş mesaj açar; mesajı kullanıcı WhatsApp üzerinden kendisi gönderir.
- Telefon numarası ve iletişim bağlantıları talep edilen `0542 410 57 44` bilgisine ayarlanmıştır.

## Dosyalar

- `index.html` — erişilebilir ve SEO temel bilgileri eklenmiş sayfa yapısı
- `styles.css` — masaüstü ve mobil tasarım
- `script.js` — mobil menü, kategori filtreleri, fotoğraf büyütme ve teklif formu
